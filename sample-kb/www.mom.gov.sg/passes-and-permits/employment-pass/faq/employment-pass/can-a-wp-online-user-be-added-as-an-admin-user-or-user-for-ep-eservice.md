# Can a WP Online user be added as an admin user or user for EP eService?

Yes. You can get your company’s EP eService admin user to add you as a user.

If there are no existing EP eService admin users, you can [submit a request](https://www.mom.gov.sg/wpd-manage-online-account) to MOM.
