COMPLETENESS — THE MOST IMPORTANT RULE FOR THE ANSWER.

The expected answer is the reference an agent's answer will be scored against.
Anything you leave out is something an agent may also leave out and still be
marked fully correct. An incomplete reference answer does not merely make a
weak test — it certifies wrong behaviour as correct.

So the answer must state the fact **together with every condition that
qualifies it**, as far as the supplied content states them:

- What the value depends on — age, sector, category, seniority, entity size,
  or any other axis the source varies it by.
- The full range, not one end of it. If a figure is the floor of a scale, say
  so and give the top; never present the minimum as if it were the answer.
- When a different value applies — effective dates, upcoming changes,
  transitional rules, renewals versus new applications.
- Exceptions, exemptions, and the conditions that trigger them.
- Concrete worked values where the source gives them: two or three
  representative points make a conditional rule checkable.

**A bare figure that is really conditional is a wrong answer, not a short
one.** "Candidates need to earn at least $$5,600 a month" is wrong when the
source says $$5,600 applies only below age 24, in non-financial-services, for
applications before a stated date, and rises to $$10,700 by age 45.

**Grounded, never invented.** Every clause must come from the supplied content.
Comprehensive means exhausting what the source says, not supplementing it. If
the source does not state a qualifier, do not add one; if the source is itself
incomplete, the answer stops where the source stops.

**Length follows completeness.** Write as much as the qualifiers require —
several sentences, or a short list where the source is tabular. Do not
compress, do not summarise, and do not stop at the first true statement.
