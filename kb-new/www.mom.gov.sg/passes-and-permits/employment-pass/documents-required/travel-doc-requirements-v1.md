Travel document requirements 
 
Things to note 
• Upload only the latest copy of the travel document. 
• We only need the biodata page of your travel document. Provide the 
Amendments/Observation pages only if they show changes to the biodata page details. 
• Save each page as a single image file. Acceptable file formats are jpg, png and pdf. 
• Ensure the image is in landscape format and the right way up. 
• To avoid delays in the processing of your application, please ensure you have met all these 
requirements. 
 
How to prepare your document for upload 
1. Provide a large, close-up colour copy of the biodata page. The image and text must be 
clear. The photograph must clearly show all facial features (eyes, ears, mouth, nose, chin).
